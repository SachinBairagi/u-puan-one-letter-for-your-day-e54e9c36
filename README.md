One letter for the day: **F**, for Friday-feeling. That light, electric lift when the week finally tips over into the weekend, the shoulders drop, the plans start forming, and everything suddenly feels possible. No other letter carries a whole mood in a single stroke, so this program writes exactly one character, F, and nothing else.
